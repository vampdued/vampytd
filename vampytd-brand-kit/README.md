# VampYTD Brand Kit v1.0

Open `index.html` in a browser for the full guidelines (logo usage, clear space, colour, type, downloads).

## Folders
| Folder | Contents |
|---|---|
| `logo/` | Horizontal, stacked and wordmark logos as SVG, each in `color`, `reverse`, `black`, `white` |
| `icon/` | The play-button icon as SVG in the same four colourways |
| `app-icon/` | App tiles (light, dark, red), full-bleed versions for iOS, and a maskable version for Android/PWA |
| `favicon/` | `favicon.svg` (switches to a white triangle in dark browser themes), `.ico`, apple-touch-icon, Android icons, `site.webmanifest` |
| `social/` | Open Graph 1200x630, X header 1500x500, YouTube banner 2560x1440, 800px avatars |
| `png/` | Ready-made PNGs of the logos, icons and app icons |
| `tokens/` | `colors.css` (CSS custom properties with light/dark), `tokens.json`, `tailwind.colors.js` |
| `fonts/` | Inter Regular, SemiBold, Bold, Black (SIL Open Font License 1.1) |

## Colours
| Name | HEX | Use |
|---|---|---|
| Vamp Red | `#FF0A21` | Icon ring, "YTD", key actions |
| Ink | `#0E0E12` | "Vamp", play triangle, text, dark surfaces |
| White | `#FFFFFF` | Light surfaces, reverse wordmark |
| Red Deep | `#E00019` | Red text and links on light (5.0:1 on white) |

Vamp Red on white or white on Vamp Red is 3.9:1: use for large text and graphics only.

## Quick rules
- Use the supplied files; never retype, recolour, stretch or add effects.
- Keep clear space of x around the logo (x = half the cap height of the V).
- Minimum widths: horizontal 120 px, stacked 72 px, wordmark 90 px, icon 16 px.
- Dark backgrounds: reverse logo. Red backgrounds: white logo. One-colour print: black.

Logo text is Inter Black converted to outlines, so no font is needed to display it.
